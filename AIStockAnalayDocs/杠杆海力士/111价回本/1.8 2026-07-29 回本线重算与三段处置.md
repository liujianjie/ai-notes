**2026-08-03 起 07709 改为灵活杠杆结构**，每日杠杆在 2 倍上限内浮动，极端市况最低 1.1 倍。本篇所有数字已按这个新规则重算。

## 8/3 的规则变更

# 以下是原理

## 一、灵活杠杆改变了什么

多日持有的收益近似：

```
产品因子 ≈ (正股涨幅)^L × exp(−(L(L−1)/2 · σ² + 成本) · 时间)
```

L 从 2 降下来，两件事同时发生，方向相反：

- **平方效应减弱**（坏）：L=2 时正股涨 28% 产品涨 65%，L=1.3 时只涨 39%
- **衰减系数减弱**（好）：L(L−1)/2 从 1.0 降到 0.195，损耗几乎消失；融资成本也随敞口下降

净效果取决于要涨多少。**小涨幅里损耗节省占优，大涨幅里平方效应损失占优。** 而回本需要 3.4 倍，属于大涨幅，所以杠杆下调对回本是净利空。

正股到 180 万时的产品价（一个月，含溢价回归）：

| 杠杆 | 产品价 |
|---|---|
| 2.0 | 46 |
| 1.5 | 43 |
| 1.3 | 42 |
| 1.1 | 40.5 |

反弹收益确实打折，但只打了 12%，比直觉小——因为损耗同时降了。

一年内的回本线就完全是另一回事：

| 杠杆 | 12 个月回本需要正股 |
|---|---|
| 2.0 | 381 万 |
| 1.3 | **415 万** |
| 1.1 | **455 万** |
| 1.0（换正股） | 477 万 |

**灵活杠杆让 07709 越来越像 1x**：上行弹性被削，但归零风险和成本也同步下降（见第八节）。它不再是彩票，变成一个更温和、也更没特点的产品。

模型参数：σ 分档取 1 个月 100%、3 个月 95%、6 个月 85%、12 个月 75%、36 个月 70%（近期实证约 150%，按逐步回落处理）。成本按 `2% 管理费 + (L−1) × 19% 融资` 估算，19% 那部分是实证反推，非官方披露。

## 二、为什么 1.2 倍是临界点

把「留在 07709」和「换成正股」放在同一个月、同一个正股涨幅（+28.5%）下比：

| 杠杆 | 22,596 变成 |
|---|---|
| 1.5 | 30,330 |
| 1.3 | 29,376 |
| **1.0（换正股）** | **29,032** |
| 1.1 | 28,360 |

**杠杆降到 1.1 时，07709 已经跑输直接持有正股。** 临界点在 1.1~1.2 之间。

要说清楚的是，这个临界点主要由**当前那 3~5% 的溢价**撑着，不是由杠杆本身撑的。如果溢价不回归，1.1 倍反而还略优于正股。所以真实情况是：**杠杆降到 1.2 以下时，留和换的一个月预期收益差在 ±3% 以内，已经小于溢价的不确定性。**

那为什么还是建议换？因为到那个水平，留下来多背的是「杠杆每天变、看不透」这一层不确定性，而收益差已经没了。**收益打平的时候，选确定的那个。**

这也是 8/3 这个决策点存在的全部意义：它是第一次能看到真实杠杆的时刻。

## 三、为什么回本线会往上跑

衰减项只跟波动率、杠杆和时间有关，跟方向无关。海力士 7/11 到 7/29 这 12 个交易日反推的年化波动率约 **150%**，σ 进平方，衰减极快。

按 2 倍杠杆口径（8/3 前的旧规则）：

| 持有到 | 需要正股 | vs 今年高点 298.7 万 |
|---|---|---|
| 1 个月 | 272 万 | −9% |
| 3 个月 | 297 万 | 持平 |
| 6 个月 | 326 万 | +9% |
| 12 个月 | 381 万 | +27% |
| 36 个月 | 739 万 | +147% |

**正股的回本线是水平的，杠杆产品的是斜线。**「再等等看」在这类产品上从来不是中性选择。杠杆下调会让斜线变平，但同时把起点抬高。

## 四、为什么「不再亏」也要花钱

衰减跟方向无关，正股原地不动产品也会跌。按 2 倍口径：

| 目标 | 价格 | 1 个月内需要正股 | 6 个月 |
|---|---|---|---|
| 亏 50% | 55 | 192 万 | 231 万 |
| 亏 60% | 44 | 172 万 | 207 万 |
| 就地不动 | 32.28 | 147 万 | 177 万 |

想让它停在 32.28 别动，正股 6 个月内得涨 26%。杠杆下调后这个要求会降低，这是灵活杠杆唯一实打实的好处。

## 五、为什么触发价是 44

3.4 给的反弹主目标区是 **165~185 万**。44 对应正股 176~187 万（随当时杠杆浮动），压在这个区间的上沿。

1.7 定的 60 需要正股 206 万，落在区间外面，属于 3.4 里只给 10% 概率的那一档——**兑现线设在目标区外面，等于给自己设了个大概率碰不到的价**。

上一版本分 46/57 两档，是按固定 2 倍算的。杠杆浮动之后第二档要到正股 228 万才能摸到，已经离谱，所以并成一档。

## 六、换 1x 不等于看好 2029~2030

这两件事必须分开。

**换 1x 解决的是确定的问题**：停止衰减，以及摆脱杠杆倍数的不确定性。不需要任何预测就成立。

**换完之后能不能涨回来是另一个问题。** 海力士 2029~2030 的位置，主观赔率：

| 区间 | 概率 | 含义 |
|---|---|---|
| ≥477 万 | **15%** | 1x 的回本线 |
| 300~477 万 | 25% | 超今年高点但不够回本 |
| 180~300 万 | 30% | 回到今年高点附近 |
| 100~180 万 | 22% | 现价上下震荡 |
| <100 万 | 8% | 结构性输掉 |

477 万对应的市值约是现在的 3.4 倍。海力士刚走完一轮 12 倍行情，再涨 241% 等于要变成全球前几大公司。

### 那为什么是海力士 1x

其实没有特别理由。22,596 换成任何标的，回本都要 +241%，海力士在这件事上没有特殊地位。选它的唯一理由是仓库里已有的研究积累，换新标的有认知成本。

按 3.4 的中期判断（偏空 45%、横盘 30%、偏多 25%），换成海力士 1x 之后大概率还要再承受一段下跌，只是从「每天被收税的下跌」换成「不收税的下跌」。

**第二步该放哪，不该被已经亏掉的 54,404 绑架。** 那是沉没成本。这个决策实际上是「剩下 89% 的资产怎么配」的一部分。

## 七、真正的回本该怎么算

**这 22,596 回到 77,000**，需要 +241%，概率 2~3%（留在 07709）或 15%（换 1x 后）。

**总资产回到亏损前**，这笔亏损占总资产约 11%，剩下的 89% 涨 **12.4%** 就补平了。

同一个目标两条路，难度差二十倍，而且后者是在没有杠杆损耗的正常投资里做到的。前者应该明确放弃——这不是安慰，是算术。

## 八、归零风险和成本，跟着杠杆一起降

### 归零风险：大幅下降

杠杆产品的单日归零机制是标的单日跌 1/L：

| 杠杆 | 标的单日跌多少归零 |
|---|---|
| 2.0 | **50%** |
| 1.5 | 66.7% |
| 1.1 | 90.9% |

而降杠杆的触发条件恰恰是「剧烈波动、成交激增」，也就是最可能归零的时候杠杆最低。**这是新规的核心设计意图，媒体称它为「安全阀」。** 8/3 之后归零风险从「真实存在」降到接近可忽略。

### 成本：会降，但不会消失

| 项 | 会不会随杠杆降 |
|---|---|
| 管理费 1.6% / OCF 2% | **不会**，合同费率，新规管披露不管费率 |
| 掉期/期权融资成本 | **会**，正比于借入敞口 (L−1) |

2 倍口径下总成本约 21%/年，1.1 倍口径下降到约 4%/年。降了很多，但不是零——直接持有正股才是零。

### 对 1.7 B 方案的影响

1.7 选 B 的前提是「当彩票留着，亏光也认」。8/3 之后这个前提两头都变了：**基本不可能归零，也基本不可能翻倍。**

它从「高风险高弹性的彩票」变成「中低风险中低弹性的产品」。这未必是坏事，但彩票仓的意义全在弹性——弹性被砍掉之后，B 方案的逻辑基础就不完整了。

### 一条新增的好消息

新规同时要求：swap 合成的 L&I 产品必须清楚披露与交易对手订立掉期的成本，**包括未被经常性开支比率涵盖的所有成本**。这正是本篇第十节标注为「悬空」的那个参数。8/3 之后应该能拿到官方数字，届时回本线表要用真实成本重算一次。

## 九、证伪

- 说明该多留：8/3 披露的杠杆仍是满 2 倍，且 8/26 财报确认 Rubin 放量、正股一周内站上 185 万
- 说明该更早撤：8/3 披露杠杆 <1.2 倍；DDR5 现货价见顶回落；正股跌破 124.6 万（此时触发价已失效，直接换 1x）

## 十、悬空参数

**掉期+期权成本没有官方数字**（CSOP 官网 403、KFS 拿不到），19%/年的融资部分是实证反推。每差 5 个百分点，12 个月回本线动约 20 万韩元。新规已要求披露这项成本，8/3 后应该能补上。

**管理费是否随杠杆下调而降，没有任何来源提及。** SFC 新规管的是杠杆机制、披露和更名，不涉及费率，所以默认按不变处理。这一条如果错了，方向是对持有人有利。

**韩元敞口是 1 倍还是 2 倍未知。** 基准是韩元计价、基金基础货币是 USD，中间这层换算公开资料没写，影响触发价约 3 个点。

**8/3 之后的实际杠杆路径无法预测。** 规则是发行商按容量约束自主决定、无公式，只能每天收市后被动查。本篇按 1.1/1.3/1.5/2.0 分档给结果，实际走哪条要到 8/3 才知道。
