# 以下是原理

## 一、灵活杠杆改变了什么

固定杠杆、连续近似下，多日持有的收益可写成：

```
产品价格因子 ≈ (正股价格因子)^L × exp(−(L(L−1)/2 · 已实现方差 + 成本))
```

灵活杠杆下，更接近实际的离散表达是：

```
产品累计因子 ≈ ∏[1 + 当日目标杠杆 L_t × 正股当日收益 r_t − 当日费用与跟踪差]
```

因此不能用一个固定的 L 把未来数月压缩成唯一结果。下表只用于说明方向和敏感度。

L 从 2 降下来，两件事同时发生，方向相反：

- **平方效应减弱**（坏）：L=2 时正股涨 28% 产品涨 65%，L=1.3 时只涨 39%
- **衰减系数减弱**（好）：L(L−1)/2 从 1.0 降到 0.195，损耗几乎消失；融资成本也随敞口下降

净效果取决于要涨多少。**小涨幅里损耗节省占优，大涨幅里平方效应损失占优。** 而回本需要 3.4 倍，属于大涨幅，所以杠杆下调对回本是净利空。

正股到 180 万时的产品价（一个月，含溢价回归）：

| 杠杆 | 产品价 |
|---|---|
| 2.0 | 46 |
| 1.5 | 43 |
| 1.3 | 42 |
| 1.1 | 40.5 |

反弹收益确实打折，但只打了 12%，比直觉小——因为损耗同时降了。

一年内的回本线就完全是另一回事：

| 杠杆 | 12 个月回本需要正股 |
|---|---|
| 2.0 | 381 万 |
| 1.3 | **415 万** |
| 1.1 | **455 万** |
| 1.0（换正股） | 477 万 |

较低杠杆会让 07709 的单日敏感度更接近 1x，并可能降低部分风险，但发行人会在正常市况下争取恢复 2 倍，且衍生品成本不保证与杠杆同比下降。因此不能把它描述成稳定的“温和版 1x”。

模型参数：σ 分档取 1 个月 100%、3 个月 95%、6 个月 85%、12 个月 75%、36 个月 70%（近期样本很短，不能稳定外推）。旧表成本按 `2% 经常性开支 + (L−1) × 19% 情景融资成本` 估算。19% 只是一组情景参数；官方披露见第十节。

## 二、为什么把 1.2 倍当作操作阈值

把「留在 07709」和「换成正股」放在同一个月、同一个正股涨幅（+28.5%）下比：

| 杠杆 | 22,596 变成 |
|---|---|
| 1.5 | 30,330 |
| 1.3 | 29,376 |
| **1.0（换正股）** | **29,032** |
| 1.1 | 28,360 |

在这组特定假设中，杠杆降到 1.1 时，07709 跑输直接持有正股，交点落在 1.1~1.2 之间。换一组成本、波动率或路径，交点会变化。

原文用 7/29 正股和 07709 的单日涨跌差推断“当前有 3~5% 溢价”，这个推断不成立。交易时段、汇率、跟踪差和衍生品估值都会造成差异；必须直接比较最新 NAV/iNAV 与成交价。真实情况下，1.1~1.2 倍附近的留换差异可能小于这些误差。

那为什么还是建议换？因为到那个水平，留下来多背的是「杠杆每天变、看不透」这一层不确定性，而收益差已经没了。**收益打平的时候，选确定的那个。**

这也是首个目标杠杆披露的意义：在 7/31 收市后至 8/3 开市前，第一次能看到新结构下的目标杠杆；实际杠杆仍要在标的市场收市后确认。

## 三、为什么回本线会往上跑

衰减项只跟波动率、杠杆和时间有关，跟方向无关。海力士 7/11 到 7/29 这 12 个交易日反推的年化波动率约 **150%**，σ 进平方，衰减极快。

按 2 倍杠杆口径（8/3 前的旧规则）：

| 持有到 | 需要正股 | vs 今年高点 298.7 万 |
|---|---|---|
| 1 个月 | 272 万 | −9% |
| 3 个月 | 297 万 | 持平 |
| 6 个月 | 326 万 | +9% |
| 12 个月 | 381 万 | +27% |
| 36 个月 | 739 万 | +147% |

**正股的回本线是水平的，杠杆产品的是斜线。**「再等等看」在这类产品上从来不是中性选择。杠杆下调会让斜线变平，但同时把起点抬高。

## 四、为什么「不再亏」也要花钱

衰减跟方向无关，正股原地不动产品也会跌。按 2 倍口径：

| 目标 | 价格 | 1 个月内需要正股 | 6 个月 |
|---|---|---|---|
| 亏 50% | 55 | 192 万 | 231 万 |
| 亏 60% | 44 | 172 万 | 207 万 |
| 就地不动 | 32.28 | 147 万 | 177 万 |

想让它停在 32.28 别动，正股 6 个月内得涨 26%。杠杆下调后这个要求会降低，这是灵活杠杆唯一实打实的好处。

## 五、为什么触发价是 44

3.4 给的反弹主目标区是 **165~185 万**。44 对应正股 176~187 万（随当时杠杆浮动），压在这个区间的上沿。

1.7 定的 60 需要正股 206 万，落在区间外面，属于 3.4 里只给 10% 概率的那一档——**兑现线设在目标区外面，等于给自己设了个大概率碰不到的价**。

上一版本分 46/57 两档，是按固定 2 倍算的。杠杆浮动之后第二档要到正股 228 万才能摸到，已经离谱，所以并成一档。

## 六、换 1x 不等于看好 2029~2030

这两件事必须分开。

**换 1x 解决的是确定的问题**：停止每日杠杆重置造成的额外路径损耗，以及摆脱每日杠杆倍数的不确定性。不需要方向预测就成立。

**换完之后能不能涨回来是另一个问题。** 海力士 2029~2030 的位置，主观赔率：

| 区间 | 概率 | 含义 |
|---|---|---|
| ≥477 万 | **15%** | 1x 的回本线 |
| 300~477 万 | 25% | 超今年高点但不够回本 |
| 180~300 万 | 30% | 回到今年高点附近 |
| 100~180 万 | 22% | 现价上下震荡 |
| <100 万 | 8% | 结构性输掉 |

477 万对应的市值约是现在的 3.4 倍。海力士刚走完一轮 12 倍行情，再涨 241% 等于要变成全球前几大公司。

### 那为什么是海力士 1x

其实没有特别理由。22,596 换成任何标的，回本都要 +241%，海力士在这件事上没有特殊地位。选它的唯一理由是仓库里已有的研究积累，换新标的有认知成本。

按 3.4 的中期判断（偏空 45%、横盘 30%、偏多 25%），换成海力士 1x 之后仍可能继续下跌，只是去掉了每日杠杆重置的额外路径损耗。直接持有仍有交易费、税费、汇率或 ADR 费用，不能写成“零成本”。

**第二步该放哪，不该被已经亏掉的 54,404 绑架。** 那是沉没成本。这个决策实际上是「剩下 89% 的资产怎么配」的一部分。

## 七、真正的回本该怎么算

**这 22,596 回到 77,000**，需要 +241%，概率 2~3%（留在 07709）或 15%（换 1x 后）。

**总资产回到亏损前**，这笔亏损占总资产约 11%，剩下的 89% 涨 **12.4%** 就补平了。

同一个目标两条路，难度差二十倍，而且后者是在没有杠杆损耗的正常投资里做到的。前者应该明确放弃——这不是安慰，是算术。

## 八、极端损失风险和成本不会因降杠杆而消失

### 极端损失风险：可能下降，但不能写成接近可忽略

在忽略止损机制、期权结构、价格限制、跟踪误差和流动性的线性模型里，标的单日下跌 `1/L` 会耗尽对应杠杆敞口：

| 杠杆 | 线性模型下耗尽杠杆敞口的跌幅 |
|---|---|
| 2.0 | **50%** |
| 1.5 | 66.7% |
| 1.1 | 90.9% |

这只是示意，不是产品净值底线。官方公告明确提示：采用灵活杠杆后，产品仍可能在一天内损失大部分或全部投资；止损机制也不保证产品 NAV 保留某个比例。因此不能把 8/3 后的归零或极端损失风险写成“接近可忽略”。

### 成本：取决于实际衍生品结构，不是简单正比

| 项 | 会不会随杠杆降 |
|---|---|
| 管理费 / 经常性开支 | 新规公告称费率和管理成本水平不变 |
| 掉期/期权成本 | 取决于实际掉期、期权占比和市场条件，可能下降，但不能假定严格正比于 `(L−1)` |

官方章程披露：07709 掉期费当前最佳估计约为产品 NAV 的 **4%~20%/年**；当期权投入最高达 NAV 的 49% 时，掉期和期权合计成本最佳估计约为 NAV 的 **15%~40%/年**。实际数字可能偏离，直接持有正股也仍有交易费、税费、汇率或 ADR 费用。

### 对 1.7 B 方案的影响

1.7 选 B 的前提是「当彩票留着，亏光也认」。8/3 之后这个前提两头都变了：**基本不可能归零，也基本不可能翻倍。**

它从「高风险高弹性的彩票」变成「中低风险中低弹性的产品」。这未必是坏事，但彩票仓的意义全在弹性——弹性被砍掉之后，B 方案的逻辑基础就不完整了。

### 成本披露比旧稿假设更完整

新规要求更清楚披露与交易对手订立掉期的成本，包括未被经常性开支比率涵盖的成本。7/27 章程已经给出07709掉期费及掉期/期权合计成本的最佳估计区间；半年报和年报还会披露实际费用。后续重算应使用当时最新官方区间和实际杠杆路径，而不是等待8/3后才假设会出现第一个官方数字。

## 九、证伪

- 说明短线仓仍有价值：7/31 收市后至 8/3 开市前披露的首个目标杠杆较高，且随后价格快速反弹；这只支持短线，不支持长期持有
- 说明该更早降风险：目标杠杆 <1.2 倍；DDR5 现货价见顶回落；正股有效跌破 124.6 万；或产品出现高溢价、流动性恶化、暂停交易/终止风险

## 十、悬空参数

**掉期+期权成本已有官方估计区间。** 07709 掉期费最佳估计为 NAV 的 4%~20%/年；当产品最多以 NAV 的 49%投入期权时，掉期和期权合计成本最佳估计为 NAV 的 15%~40%/年。19%只是旧模型采用的情景值。实际成本会随市场和衍生品组合变化，不能据此得到唯一回本线。

**费率不会因为这次结构变更自动下调。** 发行人公告称实施灵活杠杆后，产品费率和管理成本水平不变；衍生品实际构建成本则可能变化。

**韩元敞口是 1 倍还是 2 倍未知。** 基准是韩元计价、基金基础货币是 USD，中间这层换算公开资料没写，影响触发价约 3 个点。

**8/3 之后的实际杠杆路径无法预测。** 规则是发行商按容量约束自主决定、无公开公式；目标杠杆逐日公布，实际杠杆在标的市场收市后更新。发行人在正常市况下仍会争取维持 2 倍，并在约束消失后尽快恢复。本篇按 1.1/1.3/1.5/2.0 分档只是敏感度分析。
